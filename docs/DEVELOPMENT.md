# EasyTake · 开发与验证记录

在 [Tendedero](https://github.com/alejandrobujan/tendedero) 原生挂绳上扩展最近访问、自定义文件夹源、多文件类型，以及类型背景色和筛选。沿用原挂绳、夹子、卡片、截图动效和系统交互，不增加文件面板。

当前为 0.1.4 本地开发版：自定义来源统一按访达“添加日期”由新到旧排列，修复下载目录顺序不一致；保留预览闪退及悬停响应修复、文本和视频预览、系统最近访问、PixPin 图片载荷及类型筛选。真实跨 App 拖放、系统截图设置恢复等仍需验收，尚非全部验收完成的发布版。

## 使用

运行已安装的 `/Applications/随取.app`。F2 切换挂绳，或在屏幕最上沿连续停留 0.5 秒；移开后收起。菜单栏闪电图标也可展开挂绳。开发构建临时输出 `build/随取.app`，安装后清理该副本及旧版 `.app` 备份，只保留一个可启动的最新版。

工具条依次提供类型筛选、卡片大小、当前来源、添加日期说明、添加来源、设置和收起。来源菜单包含最近访问、剪贴板与截图及添加的文件夹。自定义文件夹只显示直属项目，统一按系统添加日期倒序取 20 项，不提供排序切换。添加日期缺失的项目排在后面，同一日期以文件名稳定排序。显示期间监听目录变化并每 2 秒补查，隐藏期间暂停，重新呼出补查；类型筛选在取前 20 项之前执行。

图片浅蓝、视频浅紫、文本暖白、普通文件浅灰绿、文件夹浅米色。点击类型按钮单选，“全部”恢复全部类型。浅色卡片上的文件名和类型说明使用深色文字，兼容系统深色模式。

保留单击复制、双击打开、图片长按标注、视频长按裁剪、Quick Look、卡片大小与保留数量、声音和登录启动。右键提供复制、预览及适用的路径和访达操作。拖动源只提供复制；取消、移除卡片或移除来源不删除用户原件。

文本文件可在预览中直接阅读、滚动和选择，剪贴板文本可选择全文；右键“预览全文”也可打开。文件文本在后台读取，支持 UTF-8、UTF-16 及 RTF 正文；超过 4 MB 时明确提示截断，可用独立的系统快速查看阅读完整文件。视频先显示静态帧，点击“播放视频”或右键同名操作后，在 AVKit 播放器中播放、暂停和定位进度；悬停不自动播放，关闭预览停止播放。文本和视频控件不覆盖整块拖放层，底部有独立拖出入口；图片大图本身仍可拖出。

剪贴板记录默认关闭，在“剪贴板与截图”来源的工具条或空状态点击“开启记录”后，下一次 PixPin/PinPix 截图复制会进入此来源；关闭不清空历史。识别 PixPin 的图片像素，避免只引用它会消失的临时文件。仅保存到文件、未复制的第三方截图，通过添加其保存目录取用。屏蔽私密/临时标记，忽略随取自己的复制。文本上限 1 MB、图片上限 64 MB、图像上限 8000 万像素、应用缓存上限 256 MB；清理仅作用于随取自行保存的资产。多文件当前分别挂为卡片。

最近访问合并本应用打开/成功拖出记录与本机个人文件范围内的 Spotlight 结果，使用真实使用时间，不要求先添加自定义文件夹。系统索引不足或权限受限时会显示说明，关闭系统查询仍保留本应用记录。系统候选排除文件夹、应用和隐藏路径，贴近访达“最近使用”；本应用自行打开或拖出的文件夹仍可保留其使用记录。首次选中最近访问，后续恢复上次来源和筛选。

截图监听系统实际保存目录，不重定向截图位置。可选“直接挂起”只备份并关闭系统浮动缩略图，停用/退出时仅恢复仍由随取管理的选项；恢复入口保留在设置中。看其他来源时新截图不会切走当前来源。

## 构建与验证

最低 macOS 14；SwiftPM、AppKit、SwiftUI 和系统框架，无第三方依赖。

```bash
swift test
swift scripts/check-strings.swift
scripts/build-app.sh release
scripts/make-dmg.sh release --skip-build
```

应用名称为随取，Bundle ID 为 `local.suiqu.app`，数据目录为 `Application Support/Suiqu`，图标为自有橙色闪电文件。构建脚本包含 Apple silicon 和 Intel 两种架构。本地无 Developer ID 时使用 ad hoc 签名；不自动上传、公证或更改外部 Homebrew 仓库。`origin` 为用户的 EasyTake 仓库，上游参考仓库保留为 `upstream`，不向上游推送。

### 0.1.2 闪退修复

- 实际安装版崩溃报告 `Suiqu-2026-10-24-204122.ips` 指向 `QLPreviewView.deactivate`；开发版另两份报告指向同一路径及 `EmbeddedPreview.dismantleNSView`。此前界面自动化期间的部分超时也发生在此崩溃期间，不能据此认为应用稳定。
- 移除 SwiftUI 挂绳预览中的 `QLPreviewView`，以原生 `NSTextView`/`NSScrollView` 显示文本、`AVPlayerView` 播放视频；播放器拆除时暂停、释放播放项目，不再调用 Quick Look 的内嵌关闭流程。独立的系统快速查看仍保留。
- 23 项自动测试通过，新增 UTF-16/截断读取，以及 30 次文本预览、15 次视频预览的实际 NSHostingView/窗口层级创建与拆除回归。这些测试验证生命周期稳定性，不代表已验收真实视频内容播放或跨 App 拖放。

### 0.1.3 悬停响应修复

- 对照参考项目：两者旧的卡片悬停等待都是 400ms；参考项目优先处理清晰预览，随取旧实现让预览与整排卡片缩略图共用 FIFO 队列，且原生进入事件与指针轮询会重复重置同一卡片计时。
- 同一卡片的待显示/已显示状态现在去重；卡片跟踪区因缩略图更新而重建时，不再取消真实悬停。等待改为 120ms；顶边呼出仍保留用户设置的独立等待时间，并将全屏判定移到实际激活时执行，避免每秒 30 次询问 WindowServer。
- 仍限制总共 3 个解码任务，改为最多 2 个卡片任务加 1 个专用预览任务；清晰预览不再排在整排缩略图之后。完整清晰缓存可同步显示，文件元数据在后台核对，不用小卡片缩略图放大充数。
- 27 项测试通过。定时器去重用例配置 50ms 等待，重复进入期间实际约 54ms 激活且仅一次；阻塞两个卡片解码器的用例中，预览仍独立完成。1800×1100 本地测试 PNG 准备 1120 像素清晰预览约 23ms，第二次同步取到缓存。上述为测试样本和回调时间，不是首次磁盘冷读、完整显示帧延迟或所有素材的性能保证。
- 0.1.2 同构建的实际挂绳界面已展开并保持运行超过 1 分钟，未新增同类 Quick Look 崩溃报告；安装文件与该构建二进制 SHA-256 一致。完整预览交互仍按下表继续验收。
